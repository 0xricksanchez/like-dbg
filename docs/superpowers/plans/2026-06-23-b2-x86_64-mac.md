# B2 — x86_64-on-Mac (in-container TCG debuggee) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** wire the in-container TCG debuggee path so an x86_64 kernel boots under QEMU-in-a-container on the Mac and a containerized gdb attaches — the *mechanism* for ADR-0001's x86_64-on-Mac case.

**Architecture:** additive for the x86_64/in-container path; arm64-native-HVF must not regress. A new `qemu_container_command` launcher wraps the QEMU argv in `docker run` (publish-to-host gdbstub, identical-path `:ro` mounts); `DebuggeeStage` owns the native-vs-container dispatch on `host.debuggee_mode`; `build_gdb_args` becomes arch-aware; `host_profile` resolves the gdbstub address by OS; the debuggee image joins the B1 manifest with a mode-aware required set.

**Tech Stack:** Python 3.12, docker-py, QEMU (TCG), gdb-multiarch, pytest, mypy `--strict`, ruff, `uv`.

**Scope note:** this plan is the **mechanism** (fully TDD-able, mergeable). The x86_64 *rootfs* needs no code change — `rootfs.sh` already does the cross-arch second stage — so it is **validated live** on the M5 (spec §3.6); a runtime failure there is a separate `systematic-debugging` follow-up, not part of this plan.

```python
    args += ["-iex", "set auto-load safe-path /", str(vmlinux)]
```

```python
def qemu_container_command(argv: list[str], *, image: str, mounts: list[Path], gdbstub_port: int = 1234) -> str:
    # In-container QEMU (x86_64-on-Mac TCG / Linux KVM). Publish the gdbstub to the host so the
    # containerized gdb reaches it at host.docker.internal:1234 (same as native-HVF). Bind each
    # artifact at its identical host path so the QEMU argv's embedded paths resolve unchanged.
    binds = " ".join(f"-v {shlex.quote(str(p))}:{shlex.quote(str(p))}:ro" for p in mounts)
    docker = f"docker run --rm -it -p {gdbstub_port}:{gdbstub_port} {binds} {image} "
    return docker + shlex.join(argv)
```

```python
"""Debuggee stage: launch QEMU — native host process (arm64-on-Mac HVF) or inside the debuggee
container (x86_64-on-Mac TCG / Linux KVM), chosen by host.debuggee_mode."""

from __future__ import annotations

from collections.abc import Callable

from likedbg.errors import BuildError
from likedbg.launchers import qemu_container_command
from likedbg.launchers import qemu_pane_command
from likedbg.pipeline import PipelineContext
from likedbg.qemu import build_qemu_argv


class DebuggeeStage:
    name = "debuggee"

    def __init__(self, *, send: Callable[[str], None], debuggee_image: str) -> None:
        self._send = send
        self._debuggee_image = debuggee_image

    def should_skip(self, ctx: PipelineContext) -> bool:
        return False

    def run(self, ctx: PipelineContext) -> PipelineContext:
        if ctx.kernel_image is None:
            raise BuildError("no kernel image in context", remedy="run the Build/Export stages first")
        argv = build_qemu_argv(ctx.settings, ctx.host, kernel_image=ctx.kernel_image, rootfs=ctx.rootfs_image)
        mounts = [p for p in (ctx.kernel_image, ctx.rootfs_image) if p is not None]
        if ctx.host.debuggee_mode == "in-container":
            cmd = qemu_container_command(argv, image=self._debuggee_image, mounts=mounts)
        else:
            cmd = qemu_pane_command(argv)
        self._send(cmd)
        return ctx
```
