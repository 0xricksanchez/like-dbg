## Environment findings (host quirks, not like-dbg bugs)

- **CachyOS glibc is x86-64-v3.** A `gcc -static` exploit (even `-march=x86-64`, because the *static
  glibc* itself is v3) **SIGILLs (rc 132)** on the baseline `qemu64` guest CPU. The `--run` delivery
  mechanism worked (delivered, `chmod +x`, executed) — the binary just used unsupported instructions.
  Fix for CTF work on this host: build exploits with **zig-musl** (`like_musl`'s
  `x86_64-linux-musl-gcc`, true baseline) — which is exactly what the foreign repack path uses, so
  the foreign `/exploit` ran fine. Alternatively raise the guest `-cpu` model.
- **`KillUserProcesses=yes` + no linger** reaped the detached tmux server on ssh disconnect. Fixed
  with `loginctl enable-linger pwn` (+ ssh `ControlMaster`/`ControlPersist` for fast polling). Needed
  for any `start_kgdb` run driven over non-interactive ssh (tmux must outlive the ssh session).
